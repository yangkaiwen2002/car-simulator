# OpenRoad

[在线驾驶 · Car Simulator](https://yangkaiwen2002.github.io/car-simulator/) · [GitHub 仓库](https://github.com/yangkaiwen2002/car-simulator)

在网页里选择车型，在同一座海港城市中第一人称驾驶。无需账号、API 密钥、AI 图片服务或 CDN。

车库默认展示「2021+ 新世代」：2021 BMW M4 Competition（G82 改款前座舱）和 2023 Lamborghini Revuelto。年份对应车型，不是模型上传年份。旧车型放在「经典收藏」，可以随时切换。

当前车库共 14 款车型：McLaren MCL39（2025，游戏增强版）、原创 W33 奔驰银河 F1、Red Bull RB19（2023）、BMW M4 Competition、McLaren P1 GTR、Lamborghini Revuelto、Ferrari Enzo、Ford GT40、Porsche 911 Club Sport、Toyota Celica GT-Four、Toyota Corolla Levin AE86、MINI Cooper S、经典 Mini 1.3 和 Mazda 3。

支持三维展厅、车型缩略图、车身配色、第一人称驾驶及车身检查视角、键盘/触屏驾驶、自动换挡、倒挡、巡航、位置地图和引擎音效。新版加入平面刚体碰撞、车辆损伤，以及纽博格林北环、蒙扎和银石单圈计时挑战。

### 更容易上手的驾驶

默认使用「公路 · 流畅易控」：面向键盘的渐进方向输入、受车速和轴荷约束的转向范围、横摆阻尼回正和渐进反打，减少松开 A/D 后的摆尾；弯中制动保留轮胎横向抓地，出弯有牵引辅助，换挡动力与座舱视角更平顺。设计目标是接近《极限竞速：地平线》的易上手风格，并非其专有物理引擎或等效复刻。它不自动走线或替你决定刹车时机。设置可切换「挑战 · 自由操控」，两种模式独立保存成绩；切换会重置本圈，0.6.2 对两种模式使用新的 v7 成绩记录，旧成绩仍保留在本机。

- 0.6.2 对全部车型的 A/D 输入重新调校：按下、换向与松开分别处理，缩短起始输入和转向机两层平滑的延迟；持续转弯仅补偿有限的正常轮胎侧偏，松键保留更强的横摆阻尼，转向力仍受轮胎抓地预算约束。公路模式 80 km/h 的 100 ms 按键测试中，全部 11 款车的初始车头转动约为 0.6.1 的 2.2–2.4 倍；公路和挑战模式均覆盖短按、左右换向检查。页面显示 0.6.2，并为入口及物理模块设置资源版本。
- 0.6.1 调整记录——减少公路模式转向不足：更快建立键盘转向、放宽中低速转角限制，提高前后轮的侧向响应；重刹和倒车保留稳定余量。干燥平路维持 80 km/h 的模拟圆周测试中，M4 转弯半径由约 59 m 减至 53 m，全部车型减小约 11%；这是游戏回归测试结果，不是实车测量。

- 前后轴分别计算侧偏角、非线性轮胎力及抓地力总量，制动、驱动与转向共享摩擦圆预算。
- 制动前移/加速后移的轴荷、质心高度和横摆惯量参与运动；重刹入弯会减少转向余量，出弯大油门可导致推头或后轮失稳。下压力与车速平方关联，参数为模拟调校。
- 刹车立即切断油门，W+S 和只按 S 的制动相同。压力渐进建立，低速保持不会误入倒挡；辅助模式有坡道静止保持。
- `Shift + W` 使用 45% 油门，`Shift + S` 使用 35% 刹车，可在键盘上练习出弯渐进给油和带刹入弯。HUD 显示前后轴抓地利用率及牵引/稳定辅助介入。
- 63 项测试覆盖制动、重量转移、联合抓地、晚刹、出弯油门、不同帧率、碰撞、损伤与三条赛道计时，以及全部车型的前后行驶转向、可动方向盘朝向、高速松键回正、连续变向、长弯和弯中重刹。干燥平路 100–0 km/h 模拟约 31–37 m，属于本版本标定结果，并非厂商实测值。

### 碰撞与损伤

- 车身碰撞形状由每个模型尺寸生成，并随车辆朝向旋转。分离轴检测、接触点冲量、摩擦和角速度让正撞、偏置碰撞与擦碰产生不同反应。
- 自适应子步把平移/转动边缘位移限制在 10 cm 内，避免高速穿过细杆。城市建筑、树干、路灯、护栏和停放车辆具有碰撞；停放车辆有质量，可以被撞开。
- 损伤使用接触消耗的能量、车身速度变化和受撞方向，分别影响动力、制动、转向与车体。外观有网格凹陷、裂纹和烟火；「查看车身」可检查损伤，「修复并重置」恢复车辆。
- 极端撞击的起火/爆炸是游戏特效，不代表真实汽车事故发生概率。车辆无软体形变、断裂零件、翻滚或完整三维悬挂求解。

### 赛道挑战

在右上角「切换场地」选择纽北（20.832 km）、蒙扎（5.793 km）或银石（5.891 km），再点击「开始挑战」。驶过计时线开始，完成一圈显示成绩，最佳圈速按车型、赛道和辅助模式保存在本机。

蒙扎、银石路线来自 `bacinger/f1-circuits` 经纬度 GeoJSON，按局部地理坐标投影为米，保持原始折线，不强行缩放成标称圈长。屏幕公里数为赛道标称长度；投影折线路径长度略有差异。固定近似路宽 12 m、地形、路肩、护栏和建筑由程序生成，不是激光扫描复刻；本模式的计时线使用数据折线起点，三分段为等距分段，并非 FIA 官方计时线和分段位置。

纽北采用 OpenTrackData / OpenStreetMap 的北环完整中心线，不是 GP 短赛道。投影后约 20.752 km，标称长 20.832 km；公开地形高程在 40 m 半径内平滑后用于道路、车身俯仰与坡度重力。约 9 m 路宽、森林护栏与设施为程序近似；没有激光扫描、真实路面横坡、Karussell 倾斜槽、车辆腾空或悬挂。挑战起点在数据原点 Hatzenbach 附近，不是官方 T13 计时线。派生路线公开位于 `public/circuits/nordschleife.geojson`，按 ODbL 1.0 提供。

全圈包含 60 个顺序检查区段。驶出白线、漏过检查点、抄近路均不能计入有效成绩；倒着穿过起点不能开圈。重置会放弃本圈，暂停不计时。当前是本地个人挑战，无联网排行、防篡改或 AI 对手。

## 启动

安装 Node.js 22 或更新版本，在本目录运行：

```sh
npm start
```

打开 http://localhost:4173/ 。无依赖需要安装。点击「开始驾驶」直接进入；资源加载失败会显示错误和重试入口。

运行检查：`npm test`。

网站全部位于 `public/`，可以直接由静态服务器托管。所有引用使用相对地址，也可放在 GitHub Pages 的仓库子路径。`.github/workflows/pages.yml` 已准备好：仓库创建后在 Settings → Pages 选择 GitHub Actions，推送 main 可部署。不会将 `.env`、用户图片或原型生成结果包含在发布目录里。

## 操作

- W / ↑：油门；S / ↓：刹车；A、D / ←、→：转向；空格：手刹。
- R：停稳后在前进和倒挡之间切换；也可点 R / N / D 按钮。
- 拖动：环顾；Q / E：看左右；C：回正。
- Esc / P：暂停。切换窗口自动暂停。
- 35 km/h 巡航只控制车速，需自己转向，刹车会取消。
- 设置提供操控辅助、画质、视野、坐姿高度和音量；移动端显示方向与踏板按钮。

## 实现和真实性范围

渲染使用本地 Three.js r180。八款旧车型的模型、贴图、声音与原始 .car 配置来自 FirstDrive/VDrift；P1 GTR 和 Revuelto 模型来自 ALIEEEN，分别使用原 GLB / glTF。新加入的 BMW M4 G82 来自 SLB（现署名 Sloftm_Carz），CC BY 4.0；原模型保留 1,492,320 个三角面和原始贴图，顶点去重后几何文件从 120.7 MB 降到 54.5 MB，仍需首次下载较大资源。十一辆车使用独立的质量、扭矩曲线、齿比、主减速比、轴距、转向角和轮胎尺寸；模拟以 120 Hz 固定步长运行。

M4 使用独立数字座舱、中控和带按键的原车方向盘，完整方向盘组件随转向旋转；制动卡钳随前轮转向而不随轮胎自转。375 kW / 650 Nm、8 挡齿比、主减速比、轴距和基础轮胎尺寸参考 BMW 2021 年技术规格；扭矩曲线、惯量、抓地与刹车为本项目调校。仪表与中控仍是静态原图，实时速度和挡位看 HUD，后视镜尚无实时后方画面；声效使用社区占位录音。

这版是可以玩的驾驶原型，并未覆盖世界上大部分车型。模型较旧，Enzo 的仪表细节、Mini、Mazda 3、911 和 Cooper S 的座舱尤其简化，内饰精度仍待升级；Celica 和 Mini 在原模型空白仪表位置增加了自制功能仪表（不是原厂仪表艺术图）；Mazda 3 的原始仪表未动态化，实时速度和转速显示在屏幕仪表中；八款旧车方向盘使用资源库共用模型；P1 GTR 的原始赛车方向盘已从合并内饰中分离并接入转向动画，默认坐姿已校正；其原始内饰贴图仍较简单，仪表未动态化。Revuelto 使用自己的可动方向盘，仪表仍为静态贴图；后视镜尚无实时反射。画面不是摄影级扫描。P1 GTR / Revuelto 的名义功率、排量、驱动形式和挡位数参考厂商资料，其余动力曲线、齿比、质量、惯量、制动与抓地力为本项目标定；混动只用一条合成扭矩曲线，没有电池、能量回收或 DRS，两辆车的引擎声音使用 EF/CO 占位录音。社区及项目参数不是原厂认证数据，车辆名称仅用于标识模型。

物理采用自制双轴轮胎力与平面刚体求解器；车辆沿道路高程贴地，坡度参与重力。轮胎侧偏、重量转移和联合抓地决定弯道表现，服务刹车使用理想 ABS 限制。它仍不是完整三维物理引擎，不含轮胎温度/转动惯量、完整悬挂、翻滚或软体求解，也没有厂商实车验证。城市为固定程序生成地图，含道路、街区、商店、树木、静态停车、灯杆、交通灯与海岸；没有动态交通、行人或红绿灯执法。碰撞使用平面刚体接触，损伤与视觉变形是游戏近似。

要扩展到高精度大量车型，需逐辆获得允许网站分发的模型（独立座舱、仪表、方向盘、玻璃和车轮），记录授权并核对厂商规格。不要给通用车壳改名称冒充另一款车。

## 扩展车型

当前 JOE 管线：在 `public/vehicles/cars/<ID>/` 放置 .car、模型、贴图和作者/许可文件，在 `public/driving/catalog.js` 注册车辆信息与适配坐姿。配置解析和车辆动力位于 `catalog.js` / `physics.js`；JOE 模型加载位于 `joe.js`；新 glTF 管线位于 `gltf-vehicle.js`，需在车型注册 `format: gltf`、模型路径、归一化长度和坐姿；固定城市位于 `city.js`。增加车型必须更新归属与许可，再验证车身、座舱、贴图方向、尺寸、视角、轮胎与物理参数。

## 0.7.0 · RB19

新增 Redgrund 的 2023 RB19（CC BY 4.0），通过 n1lays1ngh/Racing-Game 的公开压缩模型镜像取得；保留涂装、Halo、原方向盘和四轮动画。方向盘屏幕显示实时速度、档位和转速灯。813 kg 含模拟燃油，735 kW 近似曲线，高下压力随速度平方增长，专用快速转向。参数为游戏调校，非车队实测；发动机声音暂用已有占位音效。低速满舵时长轴距与较大转角产生的车身侧向速度区别于高速失稳，测试分别约束。

三赛段计时采用当前路线的三等距挑战分段，非 FIA 官方计时点。圈速与分段按 120 Hz 模拟步和过线插值计算；实时差值由同车、同赛道、同辅助模式的个人最佳圈检查点时间插值得到。紫色是本机个人赛段最佳，绿色快于个人最佳圈对应段，黄色未提升，无联网全场成绩。有效圈才更新纪录；完成圈三段保留显示 6 秒。轻微出界允许 0.8 秒返回，深度出界超过道路半宽外 6 米、持续出界、逆行和漏检查点仍无效。新计时记录使用 v8，与旧版本隔离。

## 0.8.0 · W33 银河概念

W33 为用户命名的幻想赛车，不对应真实奔驰车型。衍生使用已有 CC BY 4.0 Redgrund 方程式底盘，移除原品牌贴图并添加原创银色、青绿与银河材质。配置功率 1396.5 kW，扭矩曲线与下压力系数均比本游戏 RB19 增加 90%；并不代表圈速或极速增加 90%。90 秒平地全油门测试约 424 km/h，对照 RB19 约 312 km/h；200 km/h 定速转弯约 4.9g，为幻想调校。

轻微出界可重复，次数不限；每次连续出界容错由 0.8 秒延长至 2 秒，超过路边 6 米、持续出界、逆行或漏检查点仍无效。新成绩保存在 v9，避免与旧规则比较。


## 0.9.0 · McLaren MCL39

新增 shunqi 的独立 MCL39 社区模型（CC BY 4.0），保留木瓜橙涂装与 Halo，四轮独立转向/滚动。原模型没有独立方向盘，本项目补全近似赛车方向盘与实时档位/车速/RPM 屏幕。动力、座舱和音效均不是车队官方数据。

按用户要求，以本游戏 RB19 为基准增强：功率和扭矩 +25%；120 Hz 平地测试极速 394 对 312 km/h（+26%），0–100 为 2.13 对 2.65 秒，0–200 为 3.93 对 5.05 秒；200–0 刹停距离 47.3 对 57.3 米。80/120/200 km/h 定速过弯横向加速度提升约 23% / 26% / 30%。这些结果是游戏基准测试，不代表真实 MCL39 比 RB19 快这些幅度。

## 0.10.0 · 宽版红牛环、车手标杆与精细操作

新增基于 MIT 授权经纬度数据的红牛环（历史 4.318 km 路线、10 弯），采用 16 米加宽路面、平面地形，作为默认入门场地。四条赛道均有铜/银/金游戏目标和来源可核对的历史车手圈速。选择赛道后选择目标，驾驶 HUD 显示目标预算剩余与完圈差距；只有通过原有检查点与赛道边界规则的有效整圈才能达成，个人最佳按车型、赛道、辅助模式存储，重开后恢复达成标记。

真实标杆明确标注场次和类型：红牛环采用 2020 奥地利排位，蒙扎采用 2025 意大利排位，银石采用 2020 英国排位。它们不是实时生涯最快榜。纽北使用贝洛夫 1983 Porsche 956、伯恩哈德 2018 Porsche 919 Hybrid Evo 的非 F1 纪录，标注历史布局差异。游戏加宽路面、近似物理和增强车不构成现实比赛的公平对比；没有伪造车手分段遥测。

键盘/触屏短按转向先给小幅修正，连续按住约 0.3 秒达到原有满转向；按车速及方程式快速转向参数调整增长时间，模拟步长独立于显示帧率。Shift 提供 34% 精细转向范围、28% 油门、22% 刹车；普通 S 保持完整制动。松油门采用短暂平滑释放，踩刹车立即切断油门。方向键反向/松开、暂停和重置均清理输入计时。新操控版本使用 v10 成绩分区，旧成绩仍保留但不混入新挑战。
